# 量潮游戏研发

## 概述

游戏研发——玩法设计、内容生产与工程实现。

## 目录

- `apps/` — 应用：qtgame（业务入口）、qtgame-tycoon（模拟经营）、qtgame-war（战旗）、qtgame-love（恋爱）
- `data/profile/` — 工作档案：按项目的上架与运营资料，首收 qtgame-tycoon 的 TapTap 上架资料
- `docs/gallery/` — 案例集：按阶段的工程案例，首收发布站 TapTap H5 小游戏上线工作流
- `data/library/` — 参考资料：发行平台、工具与规范，首收 TapTap 上架参考
